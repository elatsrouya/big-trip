# הטיול הגדול

אפליקציית תכנון לטיול הגדול של אלעד. אתר סטטי (HTML/CSS/JS בלי שלב בנייה) שמתארח ב־GitHub Pages ונשמר למסך הבית באייפון.

- `js/config.js` – מפתח Google Maps ומגבלות השימוש היומיות והחודשיות.
- `js/data.js` – יעדים, מדינות, אירועים והמלצות.
- הנתונים האישיים (מסלול, חיסכון, משימות) נשמרים רק במכשיר.
